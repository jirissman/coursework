from IPython.display import display, Math
import numpy as np

def display_matrix(matrix, name):
    matrix_str = "\\begin{bmatrix}"
    if matrix.ndim == 1:
        matrix_str += " & ".join(map(str, matrix)) + " \\\\ "
    else:
        for row in matrix:
            matrix_str += " & ".join(map(str, row)) + " \\\\ "
    matrix_str += "\\end{bmatrix}"
    display(Math(r'\mathbf{' + name + '} = ' + matrix_str))

f. Now, how would you use $A^+$ to solve $A𝒃 = c$? Is this solution exact or approximate?¶

The same procedure for the inverse matrix would be applied using the pseudoinverse matrix.*

  1. If $A𝒃 = c$
  2. Multiply both sides by $A^+: A^+A𝒃 = A^+c$
  3. Since $A^+A \approx I$ (approximates the identity matrix): $I𝒃 \approx A^+c$
  4. Therefore $𝒃 \approx A^+c$

The pseudoinverse gives an exact solution when one exists, such as when the matrix is a square matrix. When no exact solution exists, it provides the best possible approximate solution in terms of least squares. Since there is no exact solution in this exapmle, the solution is approximate.

4. Cross Validation.¶

(References: [GBC16] Sec. 5.2 and 5.3, [BB22] Sec. 1.2.4 – 1.2.6)

a. Using the function $\mathscr{L}(\mathbf{𝒘}, \lambda)$ discussed in class, explain why the optimal regularization coefficient, $\lambda^*$ cannot be learned from $\mathscr{D}_{train}$, and requires a separate validation set. Assume we’re using 2-norm regularization. Recall that we defined¶

$$ \mathscr{L}(\mathbf{w}, \lambda) = \dfrac{1}{\mathscr{N}_{train}} \sum_{i=1}^{\mathscr{N}_{train}} {(y_i-\hat{y}_i)}^2 + \lambda{\|\mathbf{w}\|}^2_2 $$ The optimal regularization coefficent cannot be learned from the training dataset alone because such a process will yield $\lambda^*=0$, which defeats the purpose of regularization. Regularizaiton is specifically designed to prevent overfitting to the training data by adding the penalty term. If the optimal regularization coefficient is leraned from the training data only, then a better fit will always be achieved with less regularization. A better fit to the training data results in lower training error, but this counteracts the goal of regularization to prevent the overfitting. By using a validation set or employing cross-validation, whenever overfitting occurs during training, it will be counteracted by regularization during validation.

b. Consider the steps involved in cross-validation for the specific case of polynomial regression.¶

  • Assume the dataset contains 2-dimensional features (i.e., $k = 2$), and we’re using polynomials of degree $d = 3$. How many terms will the predictor $\mathscr{h}(\mathbf{w},x)$ have?
    The predictor $\mathscr{h}(\mathbf{w},x)$ will have $\dfrac{(k+d)!}{k!d!}=\dfrac{(2+3)!}{2!3!}=\dfrac{120}{12}=10$ terms.

  • Write the full form of the predictor $\hat{y}=\mathscr{h}(\mathbf{w},x)$ showing all the constant, linear, quadratic, and cubic terms (including interaction terms).
    $$\hat{y}=w_0+w_1x_1+w_2x_2+w_3x_1^2+w_4x_2^2+w_5x_1x_2+w_6x_1^3+w_7x_2^3+w_8x_1^2x_2+w_9x_1x_2^2$$

  • What happens to the $\lambda^*$ that is found during the cross-validation process? With what data and loss function are the final weights computed before the testing phase begins?
    The $\lambda^*$ that is found during the cross-validation process is kept fixed when cross-validation is complete. Since it is now the optimal regularization parameter, it should not be discarded or changed for the final training. The final weights, $\mathbf{w}^*$ are computed in the final training phase using all of the training data (combining all of the folds) and the $\lambda^*$ found from the cross-validation process. The complete loss function that is used to compute the $\mathbf{w}^*$ is $$\mathscr{L}(\mathbf{w})=\dfrac{1}{\mathscr{N}_{train}}\sum_{i=1}^{\mathscr{N}_{train}}{(y_i-\hat{y}_i)^2} + \lambda^*{\|\mathbf{w}\|}_2^2$$
